# Manuvers

Un avatar 3D qui vit sur un écran dédié et réagit à vos automatisations : il fait signe quand une tâche se termine, saute de joie à l'arrivée d'un prospect, s'inquiète d'une relance en retard, se penche vers vous quand la veille est prête.

## En bref

- Application Mac native (Tauri), lancée à l'ouverture de session, pilotable depuis la barre des menus.
- Mode scène : plein écran sur l'écran dédié. Mode flottant : petit avatar transparent sur le bureau.
- Canal de notifications ntfy : un simple appel HTTP depuis n'importe quelle automatisation.
- Rien ne se perd : les notifications reçues pendant une absence sont rattrapées au retour.
- Écran maintenu allumé pendant vos heures de travail.
