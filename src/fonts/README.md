# Polices embarquées

Sous-ensembles latins téléchargés depuis Google Fonts, tous sous licence SIL Open Font License 1.1 :

- Bricolage Grotesque (700) : titres
- Atkinson Hyperlegible (400, 700) : texte
- JetBrains Mono (400) : heure, code

Elles sont locales pour que Manuvers fonctionne sans connexion à un CDN.
